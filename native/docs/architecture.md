# Tessera Native Architecture Status

> 状态：历史 Iced 架构已冻结，不再是活动实现规范。
>
> 当前唯一有效的 native 方案是仓库根目录的 [`makepad-plan.md`](../../makepad-plan.md)。

2026-08-26 起，Tessera 停止 Iced 路线并计划以 Makepad 重新实现 native UI。旧的 Iced 架构、spike、依赖和验收材料只保留在 `feat-iced` 历史分支，用于审计和回溯，不能作为当前实现、兼容性或发布结论的依据。

在 Makepad M0 的真实工具链、GUI、IME、AX、性能和移动端证明完成前，native 发布状态保持 `BLOCKED`。不得把本说明、旧 Iced 测试、Makepad 源码审阅或静态编译结果宣称为产品验收通过。
